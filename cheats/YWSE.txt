# Cheats do projeto para Sonic Chronicles: The Dark Brotherhood (USA), código YWSE.
# O que cada um faz, por que funciona, o nível de confiança e como testar:
#   docs/CHEATS.md
#
# Formato:
#   @pasta Nome      os cheats seguintes ficam nesta pasta
#   @escolha Nome    pasta em que só um cheat pode ficar ligado (a marca "um só
#                    ativo" do formato, que o Pico Launcher lê): usada quando os
#                    cheats mexem no mesmo endereço e brigariam entre si
#   [Nome]           um cheat; ";" na linha seguinte = descrição (aparece no cartão)
#   ENDEREÇO VALOR   linhas do Action Replay DS
# Nomes e descrições sem acento: a fonte do launcher pode não ter os caracteres.
#
# Confiança (repetida na descrição de cada cheat):
#   [DS]    testado no DS real (08/10/2026, R4i-SDHC Gold Pro + Pico Loader v1.6.0
#           DSTT), a olho: ligou, o jogo rodou e o efeito foi o esperado
#   [alta]  endereço já testado no DS, só o valor é novo; ainda não testado
#   [media] endereço conferido só no emulador; ainda não testado
#
# Antes de gravar no cartão:
#   python3 analise/tools/ar_codes.py validar cheats/YWSE.txt
#   python3 analise/tools/usrcheat.py inserir usrcheat.dat cheats/YWSE.txt saida.dat
